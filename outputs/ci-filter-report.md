# Native CI path filtering

Native jobs now depend on a read-only Ubuntu change-classification job. Mac sources select macOS; iOS sources select iOS; shared Apple sources, resources/fonts, native CMake, shared scripts and workflows select both. The iOS smoke driver and focus log parser select only iOS. Portable core runs for core sources, CI scripts/workflows and unknown native dependency directories. Documentation-only edits skip native builds and reports, including Markdown nested beside Apple, core and platform sources. Bundled font license text still selects both Apple builds. Manual dispatch selects all targets. Per-PR concurrency cancels superseded native runs; manual runs share a group by ref.

For PR synchronize events, a present previous commit is checked for existence and ancestry before comparing the latest push. Thus a documentation-only followup skips builds even if the PR previously changed native code, and an iOS followup does not repeat an earlier Mac build. Open/reopen and missing/non-ancestor previous commits use the complete merge-base-to-head PR diff. Full checkout history supplies base/head objects without writes or API permission requirements; fork reports remain disabled. Renames are treated as deletion plus addition, selecting both affected platforms. Reports explicitly skip if their platform build skipped; no report is generated from old artifacts.

Validation: `python3 -m unittest discover -s native/scripts -p test_ci_paths.py` passes 3 tests with platform/dependency/docs scenarios and a real temporary Git repository covering cumulative commits, docs-only synchronize, iOS-only synchronize, unavailable previous commit fallback, rename/deletion, and base branch advancement. `native/scripts/quality.py` passed with clang-format 19.1.7 and cpplint 2.0.2 installed in `/tmp/neon-ci-tools`. No live GitHub run was triggered or claimed.

Cancellation guards retain reports for failed builds, but prevent cancelled/superseded workflows from launching report jobs or publishing evidence. A workflow contract regression verifies both caller guards and the reusable publish guard.
